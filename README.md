# Draw Shapes on Base

An onchain gacha with real ETH-backed NFT prizes on Base (chain 8453), built on a fork of FWA's
NFT custom-pool engine. Players pay ETH for a verifiably random draw from a board of Shapes and
Draw Packs; every prize holds redeemable ETH.

This repository is under development in three milestones. Nothing here is deployed to Base mainnet.

See `docs/` for the specification of each milestone.
